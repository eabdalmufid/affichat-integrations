# @affidev/n8n-nodes-affichat

[![npm version](https://img.shields.io/npm/v/@affidev/n8n-nodes-affichat.svg?color=00A884)](https://www.npmjs.com/package/@affidev/n8n-nodes-affichat)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Official n8n community node for [AffiChat WhatsApp Gateway](https://chat.affidev.com).

This package enables bidirectional automation with WhatsApp inside n8n:
- **AffiChat (Action Node)**: Send WhatsApp messages, manage broadcast campaigns, list groups, and validate phone profiles across 19 API operations.
- **AffiChat Trigger (Webhook Listener)**: Trigger n8n workflows in real time upon incoming WhatsApp messages (`messages.upsert`) or connection status changes (`session.status`).

---

## Nodes Included

### 1. AffiChat (Action Node)
- **Message Operations (8)**:
  - Send Text (with Spintax `{Halo|Hai}` and dynamic variable replacement)
  - Send Image (URL or Base64 with caption)
  - Send Document (PDF/DOCX/XLSX with custom filename)
  - Send Video (MP4)
  - Send GPS Location (Latitude, Longitude, Name, Address)
  - Send Contact (vCard 3.0)
  - Send Sticker (WebP)
  - Send Interactive Poll (Single or Multi-select)
- **Broadcast Operations (6)**:
  - Send Bulk (Scheduled queue with rate limiter and anti-ban safeguards)
  - List Campaigns
  - Get Campaign Progress and Status
  - Pause Campaign
  - Resume Campaign
  - Cancel Campaign
- **Group Operations (2)**:
  - List Joined WhatsApp Groups
  - Get Group Metadata and Participants
- **Utility Operations (3)**:
  - Check API Key and Quota Limits
  - Check WhatsApp Phone Profile (Bio, Profile Picture, Registered status)
  - Gateway Health Check

### 2. AffiChat Trigger (Webhook Node)
- **Supported Events**:
  - `messages.upsert`: Real-time incoming WhatsApp messages with sender metadata and media attachments.
  - `session.status`: Connection state changes (`connected`, `disconnected`, `qr_ready`).
  - `*`: Catch all events.
- **HMAC Verification**: Built-in cryptographic verification against the `X-AffiChat-Signature` header.
- **Event Filters**:
  - `Sender Filter`: Restrict trigger execution to specific phone numbers.
  - `Ignore Self Messages`: Automatically skip outgoing messages sent from your own WhatsApp account.

## Installation

Inside your n8n instance:
1. Navigate to **Settings > Community Nodes**.
2. Click **Install a community node**.
3. Enter `@affidev/n8n-nodes-affichat` in the **npm package name** field.
4. Check the agreement box and click **Install**.

---

## Credentials Setup

1. In n8n, create a new credential: **AffiChat API**.
2. Enter your **API Key** generated from your AffiChat dashboard (*Dashboard > REST API*).
3. The node automatically connects securely to `https://chat.affidev.com`.

---

## Webhook Trigger Configuration

1. Add the **AffiChat Trigger** node to your n8n workflow canvas.
2. Select the event to listen for (e.g. `Incoming Messages (messages.upsert)`).
3. *(Optional)* Define a **Webhook Secret** for HMAC-SHA256 signature verification.
4. Copy the Webhook URL generated by n8n (Test URL or Production URL).
5. Open your AffiChat Dashboard:
   - Navigate to the **Webhook** section for your active session.
   - Enter your n8n Webhook URL.
   - Enter the same Webhook Secret if configured.
   - Save and activate the webhook.
